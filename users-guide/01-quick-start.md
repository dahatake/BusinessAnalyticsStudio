# Business Analytics Studio 利用ガイド（初めて使う方へ）

対象: 事業部長・Product Manager・戦略コンサルタント（顧客との議論を主導する方）。
このガイドは、**起動してから、議論の場で使い、成果物を持ち帰る**までを、画面を見ながら 30 分ほどで一通りつかめるように並べています。
コマンド操作が必要な部分（セットアップ・顧客パックの作成）は、IT 担当者や制作担当者に頼める前提で、末尾にまとめています。

> 画面は、同梱の架空企業「お手本パック」（ミズホ精機株式会社）で撮影したものです。実際の顧客パックでは、社名・色・ロゴ・データが顧客のものに替わります。

## 1. このアプリでできること

顧客との議論で出てくる「課題・解決策・優先順位・関係者・構成・計画」を、**同じデータから複数の見せ方**で同時に映し、議論しながら更新できる分析ボードです。

| 知りたいこと | 使う画面 |
|---|---|
| 結論は何か。根拠の数字と次の一手は | サマリー |
| 何から手を付けるべきか | 優先順位分析 / 2×2 マトリクス / ランキング表 |
| 課題はどう分解でき、どの解決策・製品がつながるか | 課題-解決策分析 / ナレッジグラフ |
| あるべき姿（ToBe）はいまとどう違うか | アーキテクチャ図 |
| いつ・誰が・何をやるか | ガントチャート |
| 現場・設備・拠点のイメージ共有 | 3D ビュー / 2D 図面 / 地図 / ミニ・モックアプリ |
| 議論そのものを残したい | 議論テーマ / ホワイトボード / 議論ツリー |
| 出典は何か | 出典 |
| 資料にして渡したい | エクスポート / Engagement サマリーパック |

特徴は次の 3 点です。

- **重みを変えると、順位・配置がその場で変わる**（優先順位分析 → ランキング表・2×2 マトリクス）。
- **AI の提案と、顧客が決めたことが区別して残る**（[10 章](#10-ai-機能の考え方)）。
- **サンプルと実データが混ざらない**。サンプル表示のときは画面に「サンプル」の印が付きます。

## 2. 最短の始め方（5 分）

準備担当者がセットアップ済みの場合、利用者がやることは次の 3 つだけです。

1. 表示された URL（通常 `http://127.0.0.1:4173`）を、**Microsoft Edge か Google Chrome の最新版**で開きます。iPad では Safari でも、ペン描画・指のパン／ズーム・Markdown 出力が使えます。
2. **オープニング**（社名 × Microsoft のタイトル演出）が流れます。見ずに進めるときは「**スキップ（Esc）**」を押すか、Esc キーを押します。
3. 本編が開きます。まず左のメニューから「**サマリー**」を選び、結論を読みます。

![オープニング](./images/opening.png)

顧客パックが入っていないときは、画面上部に「お手本パックで起動しています」と表示され、架空企業のデータで動きます。**練習や社内デモにそのまま使えます。**

| 下部の中央 | ショーコントロール（ミュート・音量・アニメーション・全画面など） |

ツールバーの拡大図です。

![ツールバー](./images/toolbar.png)

### 画面の並べ方を変える

各画面の右上の「…」メニューから、次の操作ができます。

- **上・下・左・右へ移動** / **並べる方向を変える（横/縦）**
- **最大化**（その画面だけを広く見る）／ **通常表示**
- **タブにまとめる**（ほかの画面と重ねて切り替える）／ **タブから出す**
- **非表示**（左メニュー下の「非表示のコンポーネント」から戻せます）
- **ピン止めする**／**ピン止めを外す**（見出しのピンのアイコンでも切り替えられます）

境界線のドラッグでも、画面の幅を調整できます。並べ方を崩したときは、ツールバーの「**既定のレイアウトに戻す**」で戻ります。

#### 画面をピン止めする

KPI/OKR やガントチャートのように、議論の間ずっと見せておきたい画面は、見出しのピンのアイコン（「ピン止めする」）で、その位置と大きさに固定できます。固定中はアイコンが塗りつぶしのピン（「ピン止めを外す」）に替わります。

- 固定した画面は、ほかの画面を動かしても押し出されず、フォーカスしても大きくなりません。ほかの画面は、固定した画面と重ならない位置に置かれます。
- ブラウザーの幅を変えても、作業領域に対する位置と大きさの比率を保ちます。狭い画面では、縦積みの先頭に置かれます。
- 固定した画面は動かせません。動かすときは「ピン止めを外す」を押してからドラッグします。
- ピン止めすると、ほかの画面も、いまの位置のまま自由に動かせる配置になります。ピン止めを外しても、この配置はそのまま残ります。分割の並べ方に戻すときは、「…」メニューの「分割の配置に戻す」か「既定のレイアウトに戻す」を使います（「既定のレイアウトに戻す」はピン止めも外します）。
- コマンドパレット（Ctrl+K）の「ピン止めの切替」でも、操作中の画面を切り替えられます。

## 5. 議論の流れに沿った使い方（おすすめの順序）

初回の議論では、次の順に画面を開くと、話が自然に進みます。

1. **サマリー** — 結論・根拠の数値・推奨アクションを確認して、議論の起点にします。
2. **課題-解決策分析** — 課題を分解し、原因・解決策・効果を確かめます。
3. **優先順位分析** — 観点の重み（インパクト・ROI・実現性など）を顧客と一緒に動かします。
4. **2×2 マトリクス / ランキング表** — 重みを変えた結果の順位・配置を見て、「今すぐ実行」「計画して実行」を決めます。
5. **アーキテクチャ図・ガントチャート** — 実現の形と計画を確認します。
6. **議論テーマ** — 決まったこと・保留を記録します。
7. **エクスポート** — 議論メモを持ち帰ります（[9 章](#9-成果物を持ち帰るエクスポート)）。

### 5.1 企業と Project に分けて、分析手法で整理する

顧客（企業）ごと・案件（Project）ごとに議論を分けて進めたいときは、画面の上部の「**企業と Project**」を使います。

1. 「**企業を登録**」で企業名を入れて登録し、「**Project を作成**」で案件を作ります。
2. Project の名前を押して**開きます**（「開いている Project: 企業名 / Project 名」と出ます）。開くと、業務改善の 5 つのステップ（**課題定義 → 現状分析 → KPI 測定 → ユースケース作成 → 施策計画**）が並び、各ステップから、関連する画面へ移れます。
3. 「**分析を開始**」で、分析手法（**SWOT 分析・ファイブフォース分析・バリューチェーン分析・3C 分析・バランスト・スコアカード**）を選びます。

![企業と Project、ステップ、分析手法の選択](./images/analysis-methods.png)

手法を選ぶと、項目ごとの「**値（0〜10）**」と「**重み（1〜5）**」を入力でき、結果（値×重み）と分類ごとの合計が、表・マトリクス・グラフで確かめられます。範囲外の値はエラーになり、結果は直前の有効な値のままです。

![SWOT 分析の結果](./images/analysis-result.png)

- 入力値は **Project ごとに、この端末のブラウザーの中だけ**に保存されます（サーバー・ほかの端末には送りません）。共有や権限の仕組みはありません。
- 「**既定値に戻す**」で入力を初期化できます。分析結果のパネルは、ボタンで位置・大きさを動かせます（「レイアウトを既定に戻す」で戻ります）。
- 「**AI 下書きを依頼**」で下書きが出ます。**採用するまで分析には反映されません**（「採用」「却下」）。
- 企業ごとに「**外部 AI への送信を許可する**」があります。**既定はオフ**で、オンにした企業だけ、外部の AI へ送れます。

## 6. 画面（コンポーネント）リファレンス

どの画面も、左メニューで選び、「…」メニューで最大化すると見やすくなります。サンプル表示中は、タイトルの横に黄色の「**サンプル**」が付きます。

### 6.1 サマリー

結論・根拠の数値・推奨アクションを、データから自動でまとめます。各画面の上部にある「エグゼクティブサマリー」も同じ仕組みです。

![サマリー](./images/screen-03-summary.png)

### 6.2 課題-解決策分析

課題を、**イシューツリー・MECE 表・サンキー図・マトリクス**で整理します。表示の形と、区分（社内向け／社外向け）を切り替えられます。「議論テーマにする」で、選んだ課題を議論の記録に移せます。

![課題-解決策分析](./images/screen-01-issue-solution.png)

### 6.3 優先順位分析

観点ごとの**重み（0〜10）**を動かすと、ランキング表と 2×2 マトリクスの順位・配置が変わります。AI の提案値と、顧客が決めた値は区別して表示されます。

![優先順位分析](./images/screen-02-priority.png)

### 6.4 2×2 マトリクス

横軸=実現性、縦軸=インパクト、バブルの大きさ=コストです。右上=今すぐ実行／左上=計画して実行／右下=手早く実行／左下=保留。「表で見る」で数値の表にも切り替えられます。

![2×2 マトリクス](./images/screen-04-matrix.png)

### 6.5 ランキング表

重み付きスコア（Σ 重み × 評価値）の高い順の表です。評価値は 1〜5。重みは「優先順位分析」で変えます。

![ランキング表](./images/screen-05-ranking.png)

### 6.6 ナレッジグラフ

課題・解決策・製品・工程などのつながりを、2D と 3D で見ます。ノードを選ぶと、指定したホップ数（1〜3）以内だけを表示します。種別のチェックで絞り込み、名前・ID で検索できます。

![ナレッジグラフ](./images/screen-06-knowledge-graph.png)

### 6.7 アーキテクチャ図

ビジネス（Capability Map・バリューストリーム）とアプリ／システムの層を見ます。**AsIs / ToBe** を切り替えると、追加（緑）・削除（赤）・変更（黄）が色とラベルで分かります。「図を出力」で図を書き出せます。

![アーキテクチャ図](./images/screen-07-architecture.png)

### 6.8 議論ツリー

議論の論点を木構造で分解します。編集モードを ON にすると、ノードの追加・名前変更・移動・削除ができ、「ツリーを出力」で書き出せます。

![議論ツリー](./images/screen-08-discussion-tree.png)

### 6.9 一覧表

課題・解決策などのデータを、表で一覧します。

![一覧表](./images/screen-09-table.png)

### 6.10 ガントチャート

工程・Feature を時間軸で見ます。**2D / 2.5D** を切り替えられ、依存関係のある工程と担当の偏りを確認できます。

![ガントチャート](./images/screen-10-gantt.png)

### 6.11 3D ビュー

現場・設備・拠点を 3D で見ます。「注釈を書く」「カメラパスを再生」「全体を見渡す」が使えます。3D の動きが重いときは、[設定](#11-表示の設定)で 3D の品質を下げます。

![3D ビュー](./images/screen-11-view3d.png)

### 6.12 2D 図面

現場のレイアウトなどを、2D の図面で見ます。

![2D 図面](./images/screen-12-drawing2d.png)

### 6.13 地図

拠点を地図上に表示します。物流など「流れ」のデータがある顧客パックでは、流れが粒子で動きます（お手本パックには流れのデータがないため、粒子は表示されません）。

![地図](./images/screen-13-map.png)

### 6.14 出典

画面の数字・主張の**根拠となる資料**の一覧です。取得日・確度・機密区分が付きます。「この数字はどこから来たか」と聞かれたときに開きます。

![出典](./images/screen-14-sources.png)

### 6.15 ミニ・モックアプリ

解決策のイメージを、動くモックで見せます。「こういう画面で使います」を、その場で見せたいときに使います。

![ミニ・モックアプリ](./images/screen-15-mock-app.png)

### 6.16 ホワイトボード

付箋・ペン・図形で自由に書き込めます。「クラスタリング」で似た付箋をまとめ、「決定事項に反映」「次のアクションに反映」で議論の記録へ送れます。**ドット投票**と**タイマー**もあります。ペンのツールバーの位置は、利き手に合わせて[設定](#11-表示の設定)で変えられます。

![ホワイトボード](./images/screen-16-whiteboard.png)

### 6.17 議論テーマ

ToBe に向けた課題を「議論テーマ」にして、選択肢・提言・根拠・決定事項を記録します。「テーマを追加」「課題からテーマを作る」「テーマを提案（AI）」で始めます。決定は**顧客の選択**として、AI の提案と区別して残ります。

![議論テーマ](./images/screen-17-themes.png)

### 6.18 キャンバス

ドラッグで移動、ホイールまたは +/- で拡大縮小、矢印キーで移動できる大きな作業面です。議題を選ぶと、その位置へ移動します。「選定理由」で、なぜその議題を選んだかを確認できます。

![キャンバス](./images/screen-00-canvas.png)

### 6.19 チャット

顧客パックについて質問できます。回答には「**AI 生成**」のラベルが付きます。

![チャット](./images/screen-19-chat.png)

### 6.20 設定パネル

テーマ・利き手・音声・3D の品質・業種プリセット・ブランド（色・ロゴ・フォント）の確認ができます。[11 章](#11-表示の設定)を参照してください。

![設定パネル](./images/screen-18-settings.png)

## 7. 議論の最中に使う機能

### 検索

ツールバーの検索欄に入力すると、**課題・解決策・製品**が候補に出ます。選ぶと、該当の場所へ移動します。

![検索](./images/search.png)

### プレゼンテーション

「**プレゼンテーションを開始**」で、議論を**チャプター**（現状の課題 → 解決の方向 → 効果と優先順位）に沿って進めます。右上の「議題 1 / 7」の矢印で議題を送ります。終わるときは「プレゼンテーションを終了」を押します。

![プレゼンテーション](./images/presentation.png)

- 画面に書き込む設定は 3 つあります: **書かない** / **一時的な注釈**（消える）/ **保存**（残る）。
- 画面下部のショーコントロールに、「プレゼンタービュー」「レーザーポインター」「全画面」などのボタンがあります（ボタンにカーソルを合わせると名前が出ます）。
- 画面下部に、いま話している議題の要点と**出典**が表示されます。

### 演出強度・アニメーション・BGM

- **演出強度**: Executive（落ち着いた動き。既定）／Showcase／Entertainment。顧客の雰囲気に合わせます。迷ったら Executive にしてください。
- **アニメーション**: 再生中／停止。動きが気になるときは停止します。OS の「動きを減らす」設定にも従います。
- **BGM・効果音**: 既定ではミュート中です。画面下部のボタン（M キー）で切り替えます。
- **時間軸**: スライダーで時点を動かし、▷ で自動再生します。

### ショート動画

「**ショート動画を書き出す**」で、縦長（9:16）・約 60 秒の動画（WebM）を、**このブラウザーの中だけで**作ります。外部には送信されません。動画には「サンプル」の透かしが入ります。

![ショート動画](./images/short-video.png)

## 8. 編集・変更履歴・元に戻す

既定は**閲覧のみ**です。誤操作を防ぐため、データを編集するには、ツールバーの「**編集モード**」を ON にします。

![編集モード](./images/edit-mode.png)

- 編集モードが OFF のとき、追加・複製・削除などのボタンは押せません（画面に案内が出ます）。
- 入力は検証され、誤った値は保存されません。
- **変更履歴**: 「いつ・何を・**AI か人か**」を一覧できます。

![変更履歴](./images/history.png)

- **元に戻す / やり直し**: 議論テーマや議論ツリーなどで使えます。
- **サンプルに戻す**: 編集した内容を、お手本の状態に戻します（お手本パック利用中のみ）。
- **保存 / 開く**: 作業状態をファイルに保存し、あとで開き直せます。

## 9. 成果物を持ち帰る（エクスポート）

### 議論メモ（エクスポート）

ツールバーの「**エクスポート**」を押すと、プレビューを見ながら書き出せます。

![エクスポート](./images/export-menu.png)

| 設定 | 選択肢 |
|---|---|
| 出力範囲 | 全体 / 画面別 / テーマ別 / 決定事項のみ |
| 形式 | `.md`（1 ファイル）／ `.zip`（Markdown と図の画像） |
| WorkIQ 由来の社内情報を匿名化する | ON にすると、社内情報を匿名化して出力 |
| フォローアップ文書も生成する | 次回アジェンダ・確認依頼事項・合意事項サマリー |

> 顧客へ渡す資料では、**機密区分**と**匿名化**を、渡す前に必ず確認してください。

### Engagement サマリーパック

ツールバーの「**Engagement サマリーパック**」で、**PDF と Markdown** を 1 クリックで作成します。議論の最後に、そのまま共有資料として使えます。

### そのほか

- 図（アーキテクチャ図・議論ツリー）は、各画面の「図を出力」「ツリーを出力」から書き出せます。
- ホワイトボードは、画面上部のボタンから PDF などに書き出せます。

## 10. AI 機能の考え方

- ツールバーに **「AI: モック」** と出ているときは、実際の AI につながっていない**ダミーの応答**です（お手本パックの既定）。内容は実在の分析ではありません。
- AI が作ったもの（サマリー・テーマの提案・チャットの回答）には、必ず「**AI 生成**」のラベルが付きます。
- **AI の提案値と、顧客の決定値は別々に保存**されます。優先順位や議論テーマで、顧客が決めた値を入れると、そちらが採用されます。
- 実際の AI につなぐには、準備担当者が中継プロセスを起動し、GitHub Copilot にサインインします（[13 章](#13-準備担当者向けセットアップと顧客パック)）。そのうえで、**設定パネルの「AI 接続」で実接続を ON** にし、企業ごとの「外部 AI への送信を許可する」も ON にします。実接続の設定は、その顧客パックでだけ有効です。送る情報の種類は、ON にする前に表示されます。

## 11. 表示の設定

左メニューの「設定パネル」で変更します。

| 項目 | 内容 |
|---|---|
| テーマ | Light / Dark / システムに合わせる（ハイコントラストは OS の設定に従う） |
| 利き手 | 右利き / 左利き（ペンのツールバーを置く側） |
| 音声 | BGM・効果音の ON / OFF |
| 3D の品質 | Low / Medium / High / Ultra。**3D が重いときは下げる** |
| 業種プリセット | 製造など。3D の見た目の既定が変わります |
| ブランド | 色・ロゴ・フォントと、その**出典・確認日・確度**の確認 |

## 12. よくある質問・困ったとき

| 状況 | 対処 |
|---|---|
| 画面が崩れた・見つからない | 「既定のレイアウトに戻す」。消した画面は、左メニュー下の「非表示のコンポーネント」から再表示 |
| 編集できない | 「編集モード」を ON にする |
| 数字を直したが元に戻したい | 「元に戻す」、または「変更履歴」で確認。お手本パックなら「サンプルに戻す」 |
| 3D が重い／固まる | 設定パネルで 3D の品質を Low か Medium に。アニメーションを停止 |
| 音が出ない | 既定はミュート中。画面下部のボタン（M キー）で解除。ブラウザーの音声許可も確認 |
| 「AI: モック」のままになる | 実際の AI につながっていない状態。設定パネルの「AI 接続」と、企業の「外部 AI への送信を許可する」が ON か確認する。ON でもモックのままなら、準備担当者に、中継プロセスと Copilot のサインインの確認を依頼 |
| 顧客のデータが出ない | 「お手本パックで起動しています」の表示がある間は、顧客パックが読み込まれていません。準備担当者に依頼 |
| 画面の文字が小さい／大きい | ブラウザーの拡大率を変更。狭い画面では、画面が縦に積まれます |
| 画面が見づらい | 設定パネルのテーマを Light / Dark に切り替え |
