#### FR-181 顧客の了承の確認の入力・記録・表示
- 要求: ファシリテーターは、顧客パック（案件）ごとに、顧客が情報の送信（AI・音声合成・手書き認識への送信）を了承したことの確認（了承の有無・確認日・確認した相手の役割と方法のメモ）を設定画面で入力でき、アプリはその記録を設定画面に表示する。了承の記録がない案件では、実接続（FR-132・FR-182）を有効にできず、顧客情報を外部へ送らない（既定はモック）。了承の記録は利用者が取り消せ、取り消すと実接続はモックに戻る。記録は端末内に保存し、個人名・顧客の機密は書かせず役割名のメモにする（この了承の記録のメモについての規則で、顧客パックの内容は FR-213・Q-037 回答のとおり対象外）。了承は利用者の自己申告の記録であり、アプリは顧客の了承の事実そのものを検証しない。「案件」の同一性は企業・Project の単位とし、デモは実 Project とは別の案件として既定で了承なしとする（デモと実 Project の了承の記録は混ざらない）。了承のゲートは、アプリの AI 呼び出し（FR-010・FR-011）に加え、パイプラインの実調査（FR-121・FR-125。LLM・WorkIQ・Web への送信）にも及び、了承の記録がなければ送信しない。FR-132 の AC-191 の有効化は、了承の記録がある案件で行う。ファシリテーターは、設定画面（了承の記録）から、表示中の案件の了承の記録を、パイプラインが `<workspace>/consent.json` から読む形式（`records` に案件の鍵ごとの了承あり・確認日・役割名のメモ。scripts/pipeline/consent.ts の形式）のファイル `consent.json` として、自分の操作でダウンロードして書き出せる。書き出しは利用者の操作のときだけ行い、中継プロセスや作業フォルダーへの自動の書き込みはしない。画面には、書き出したファイルをパイプラインの作業フォルダー（`<workspace>`）の直下に置く旨の案内を表示する。書き出すファイルには、API キー、顧客の機密、個人名・連絡先を含めない（案件の鍵は企業名と Project 名のみ）。了承の記録がない案件では書き出せない。なお AC-383 の「個人名・連絡先を含まない」は了承の記録のメモ・consent.json に限る（顧客パックの内容は FR-219 の確認の対象）。
- 決定状態: 承認済み（Q-001 2026-10-15。記録の項目は回答 A の具体化として AI が補った。利用者の確認を推奨。記録の項目の承認: 利用者承認 2026-10-15。書き出し（AC-384〜AC-386）: 承認済み（依頼 2026-10-15））　出自: 利用者決定　優先度: MUST（Q-001 回答 A の「顧客の了承を得た案件だけ」を実際に守るため）
- 上位: G-001、既定制約 C-02　出典: Q-001（回答 A）、FR-132、NFR-SEC-002、NFR-SEC-003
- 対象エンティティ: 顧客了承の記録、AI 接続　関係する状態: AI 接続状態（モック→接続済み。了承の記録が条件）　参照パラメータ: なし　関連する既存資産: なし（FR-132 の設定画面と中継プロセスを使う）
- 受入基準 AC-373: 中継プロセスに Copilot SDK を使える状態の差し替え部品をつないで起動し、了承の記録がない案件で設定から実接続を有効にしようとすると、有効にできない理由（了承の記録がない）が表示され、状態は「モック」のまま、チャットの質問に対して SDK の呼び出しが 0 回である。
  - 検証レベル: integration
- 受入基準 AC-374: 了承の確認（了承あり・確認日・確認した相手の役割と方法のメモ）を入力して保存すると、設定画面に記録が表示され、同じ案件を開き直しても残っている。別の顧客パックで起動すると「了承の記録なし」と表示される。了承を取り消すと、接続済みだった状態がモックに戻り、以後 SDK の呼び出しが 0 回である。
  - 検証レベル: integration

- 受入基準 AC-381: 了承の記録がない案件（デモを含む）に対してパイプラインの実調査（`research`・`build`。外部の LLM・WorkIQ・Web を差し替え部品で用意する）を実行すると、外部への送信が 0 回で、了承の記録がないため実調査をしない旨が出力され、モックまたは前提を置いたサンプルで進む。了承の記録がある企業・Project では送信される。デモで入力した了承の記録は、実 Project の案件の了承にならない。

- 受入基準 AC-382: 了承の入力欄と記録の表示に、了承が利用者の自己申告の記録であること（アプリは顧客の了承の事実を検証しない）が示される。
