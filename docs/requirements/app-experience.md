## 7. ブランド・演出・ショー体験

### 7.1 ブランドとデザインシステム

#### FR-058 Fluent 2 準拠のテーマ
- 要求: アプリは、Fluent 2 / Fluent UI React v9 に準拠し（トークン駆動、4px グリッド、Light/Dark/ハイコントラスト、Mica 風・Acrylic 風の表現は控えめ、Copilot UI パターン）、利用者が Light/Dark を切り替えられ、OS のハイコントラスト設定に従う。
- 決定状態: 承認済み（依頼 2026-10-09）　出自: 依頼原文　優先度: MUST（依頼原文 Must。既定制約 C-04）
- 上位: G-002、既定制約 C-04　出典: SRC-001 §7.1 FR-BR-01、SRC-008
- 対象エンティティ: テーマ　関係する状態: テーマ（Light／Dark／ハイコントラスト）　参照パラメータ: なし　関連する既存資産: なし
- 受入基準 AC-071: 標準の検証条件で、Light と Dark を切り替えると全画面の背景と文字の色が切り替わる。ブラウザーの強制カラー（ハイコントラスト）を有効にすると、文字・境界・フォーカスの表示が OS の色で描かれ、情報が欠けない。
  - 検証レベル: system

#### FR-059 ブランドランプの生成と適用
- 要求: アプリは、`brand-profile.json` に記載した企業カラーから {PARAM-017} のブランドランプを生成し、Light と Dark のテーマに適用する。
- 決定状態: 承認済み（依頼 2026-10-09）　出自: 依頼原文　優先度: MUST（依頼原文 Must。依頼原文の技術指定は createLightTheme / createDarkTheme）

- 受入基準 AC-072: ランプ生成の単体の検査で、Primary 色から {PARAM-017} の色が明度順に生成され、その中に Primary 色そのものが含まれる。

  - 検証レベル: system

#### FR-060 コントラストの自動検証と補正

### 7.2 3D・アニメーション・サウンド

- 受入基準 AC-087: 標準の検証条件で、`P` を押すと、CSS アニメーションの再生状態が停止になり、3D の描画が要求時だけになり（連続描画が止まり）、動画が一時停止する。停止中も選択・編集・エクスポートができる。もう一度 `P` を押すと再開する。
  - 検証レベル: system

- 受入基準 AC-089: 音声制御の結合の検査で、シーンを切り替えると前の BGM の音量が下がりながら次の BGM の音量が上がる（クロスフェード）。音源フォルダーが空のときは手続き生成の BGM が選ばれる。

#### FR-074 ミュートと音量の操作
- 要求: アプリは、常に表示するミュートボタン（`M`）、音量スライダー、BGM と効果音の個別の ON/OFF を備える。既定はミュートで、利用者の最初の操作で音声が有効になる。
- 決定状態: 承認済み（依頼 2026-10-09）　出自: 依頼原文　優先度: MUST（依頼原文 Must。§13.2 AC-07）

- 受入基準 AC-091: 標準の検証条件で、初回起動時はミュートの表示になっている。`M` を押すとミュートが切り替わり、ボタンの表示とアクセシブルな名前が変わる。BGM だけを OFF にすると効果音の設定は変わらない。
  - 検証レベル: system
- 受入基準 AC-193: 標準の検証条件で、初回起動の後に `M` とミュートボタン以外の操作（クリック・キー入力）をしても、ミュートの表示のままで音は鳴らない。ミュートを解除した設定を保存してから再読込すると、ミュート解除の表示で復元され、最初の操作の後に音が鳴り始める（最初の操作は音声の再生を可能にするだけで、ミュートの状態を変えない。[ASSUMPTION] A-17）。
  - 検証レベル: system

#### FR-153 KPI と OKR の定義
