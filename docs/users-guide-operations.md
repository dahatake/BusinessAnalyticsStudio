# users-guide の利用者の操作と、画面上の操作部品の照合表（FR-149）

users-guide（`users-guide/01-quick-start.md` §3〜§11、`02-meeting-playbook.md`）に書かれた利用者の操作を、画面上の操作部品に対応づけた一覧です。
ショートカットキー（`Shift+F`・`H`・`Esc`・`M` など）とコマンドパレット（FR-111）は引き続き使えますが、同じ操作の画面上の手段を必ず持ちます。
**users-guide に操作が増えたら、この表にも行を足します**（`tests/unit/users-guide-operations.test.ts` が、各行の部品の名前が `src/` にあることと、手段が空でないことを確かめます）。

- 対象外: users-guide 13 章（準備担当者の端末のコマンド操作）、FR-107・FR-119・FR-125（顧客パックの差し替えなど画面を持たない運用）。
- 「部品の名前」は、画面上のボタン・メニュー・入力欄の名前（表示文字または aria-label の一部）です。`src/` の中にこの文字列が存在することを、テストが確かめます。
- 常時見える部品（FR-150 の ComponentActions、ショーコントロール、ドック）に加えた操作は、備考に「FR-149 で追加」と書きます。
